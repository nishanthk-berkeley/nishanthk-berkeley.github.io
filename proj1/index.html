Overview

Sergei Mikhailovich Prokudin-Gorskii photographed the Russian Empire in the early 1900s using glass plate negatives that were exposed three times through red, green, and blue filters. Project 1's goal is to reassemble the three channels of each photograph into a single aligned color photo. Initially, with a brute-force single-scale search on smaller images, then with a multi-scale image pyramid so the same single-scale approach can scale to full-resolution scans without taking forever.

Part 1: Single-Scale Alignment

For the three lower-resolution JPEG images, I split each scan into the respective B/G/R thirds, then searched every integer displacement in a [−15, 15] window, while also cropping 10% of the image's shorter dimension off each border cutout to only score the actual image so the plate frame doesn't dominate the metric. G and R are each aligned independently to B using an L2 (Euclidean) distance between the overlapping channels. Shifts below are listed as (x, y).

The math: L2 distance

Let A be the (border-cropped) base channel, and Bdx,dy be the other channel shifted by (dx, dy) and cropped to the same region. For every candidate shift in the search window, the L2 (Euclidean) distance is calculated as shown below:

\[ L2(dx, dy) = \sqrt{\sum_{i,j} \left( A[i,j] - B_{dx,dy}[i,j] \right)^2} \]

This is the Euclidean distance between the two crops, computed by treating each crop as a flat vector of pixel intensities, so a smaller distance means the two crops are more similar. The chosen shift is whichever (dx, dy) in the [−15, 15]² window minimizes this distance. Both G and R are solved independently against the fixed B channel.

Part 2: Multi-Scale Pyramid

The full-resolution .tif scans are much too large to use the same single-scale brute-force search directly. The displacements between each channel can be very large (outside our original [−15, 15] window), and an exhaustive search at a large radius would be far too slow. Instead, I built an image pyramid: a custom 2×2 box-filter downsample() that recursively halves the image until it's under 800px on its shortest side, aligns at that coarsest scale with a 15px search window, then doubles the estimate and refines it with a smaller 10px window at each finer level on the way back up to original size. Every alignment below still uses the same L2 scoring as before, plus a second metric, NCC, introduced here. I ran the full set through both metrics; shown side by side below for each image.

NCC, downsampling, and the recursion

Normalized cross-correlation. Instead of an L2 distance to minimize, the NCC metric is a similarity score to maximize. Each crop is first mean-subtracted, then scored as the dot product of the two mean-subtracted crops divided by the product of their norms, which removes each crop's average brightness and overall contrast so only the pattern of variation gets compared, not the raw intensity levels:

\[ NCC(dx, dy) = \frac{(A - \bar{A}) \cdot (B_{dx,dy} - \bar{B}_{dx,dy})}{\lVert A - \bar{A} \rVert \, \lVert B_{dx,dy} - \bar{B}_{dx,dy} \rVert} \]

which is maximized over (dx, dy) instead of minimized. Because both crops are normalized this way, NCC cares about the pattern of intensity variation matching up, not the absolute brightness, so it's resistant to R, G, and B exposures not having identical overall brightness.

With the multi-scale process, we downsample the image for efficient calculation. Each pyramid level is downsampled with a 2×2 box filter, and the search itself is coarse-to-fine: the best shift found at the coarsest level is doubled to match the next level's resolution, then refined with a smaller 10px window, repeating back up to full resolution.

Alignment Failure

emir.tif

emir.tif was the only image that didn't align correctly for me. I think this was because the robe's deeply saturated color rendered very differently across the three channels, showing up as almost white in blue, somewhat dark in green, and extremely dark in red. Since NCC and L2 both assume the brightness relationship between channels stays consistent across the scene, this channel-dependent inconsistency threw off the calculations and left visible red/cyan inconsistent alignment on the turban, beard, and belt.
